# CodeForge Studio

**סביבת עריכת קוד בדפדפן, בקובץ HTML אחד, עם עוזר AI, תצוגה מקדימה חיה ואינטגרציה ל-GitHub.**
אין התקנה ואין שרת: פותחים את `index.html` ומתחילים לעבוד.

## יכולות

**עורך**
- עורך Monaco (המנוע של VS Code): צבעי תחביר, השלמה אוטומטית ומיני-מפה
- זיהוי שפה לפי סיומת, לשוניות קבצים ושמירה אוטומטית
- עץ קבצים עם תיקיות, העלאת קבצים וייצוא ZIP
- חיפוש והחלפה בכל הפרויקט (`Ctrl+Shift+F`), פתיחה מהירה של קובץ (`Ctrl+P`), שמירה (`Ctrl+S`)

**תצוגה מקדימה**
- עדכון חי תוך כדי הקלדה
- טעינת קבצי CSS ו-JS לפי הקישורים ב-HTML
- קונסולה מובנית שמציגה `console.log` ושגיאות
- מסך מפוצל עם פס גרירה, והחלפת צדדים בין העורך לתצוגה

**עוזר AI (Gemini)**
- צ'אט בעברית שמכיר את כל קבצי הפרויקט, עם היסטוריה שנשמרת לכל פרויקט
- הצעות לשינוי קוד עם הצגת ההבדלים (diff) והחלה בלחיצה
- ניתוח פרויקט וכפתור עצירה לבקשה
- ניסיון חוזר ומעבר אוטומטי למודל חלופי בזמן עומס

**GitHub**
- חיבור באמצעות Personal Access Token
- העלאת הפרויקט למאגר קיים או חדש, לענף ולתיקייה לבחירתך, ב-commit אחד
- ייבוא מאגר כפרויקט חדש
- הפעלת GitHub Pages בלחיצה

**כללי**
- ערכת נושא כהה ובהירה
- גיבוי וייבוא של כל הפרויקטים לקובץ JSON

## שימוש

1. הורד את `index.html` ופתח אותו בדפדפן
2. צור פרויקט חדש והתחל לכתוב
3. להפעלת ה-AI: פתח את ההגדרות והזן מפתח [Gemini API](https://aistudio.google.com/apikey)
4. לעבודה עם GitHub: לחץ על הכפתור **GitHub** והדבק טוקן עם הרשאת `repo`

## פרטיות

- אין שרת. הפרויקטים נשמרים ב-`localStorage` של הדפדפן שלך
- מפתח ה-Gemini והטוקן של GitHub נשמרים מקומית בלבד ונשלחים רק ל-Google ול-GitHub בהתאמה
- הקובץ עצמו לא מכיל מפתחות

## דרישות

- דפדפן מודרני וחיבור לאינטרנט (Monaco, JSZip והפונטים נטענים מ-CDN)

## הערות

- ההעלאה ל-GitHub לא מוחקת קבצים שקיימים במאגר ואינם בפרויקט
- תיקיות ריקות לא עולות, כי git לא שומר אותן
